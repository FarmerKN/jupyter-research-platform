
# 科研数据分析平台 | Jupyter Research Platform

[English](README.md) | [简体中文](README.zh-CN.md)

一个面向科研团队的自托管、多用户 JupyterLab 数据分析环境，旨在支持协作式、基于浏览器的计算与研究工作流。

本仓库用于公开介绍平台的设计目标与技术思路，**并非生产环境部署仓库**。这里不会包含部署密钥、私有基础设施细节、真实科研数据或用户文件。

## 项目概览

- **浏览器端分析**：通过 JupyterLab 开展交互式数据分析与计算工作。
- **相互隔离的工作空间**：利用 Docker 容器帮助隔离不同用户的工作环境。
- **受限访问**：面向经过授权的协作者，而不是向公众开放未经认证的 Notebook 服务。
- **共享科研基础设施**：为课题组的计算与数据分析工作提供统一入口。
- **可维护性与数据保护**：在平台维护和科研数据处理过程中重视安全与责任边界。

## 技术栈

- **JupyterLab**：基于浏览器的 Notebook 与交互式分析环境。
- **Docker**：用于容器化部署工作空间。
- **Tailscale**：为授权访问提供私有网络连接能力。
- **Python 及其他 Notebook 内核**：具体可用内核取决于实际部署环境。

用户实际可使用的服务、内核与功能以当前部署为准。本展示仓库本身不会部署或运行在线平台。

## 安全与隐私

平台面向经过授权的科研协作者。公开材料不会包含以下内容：

- 密码、访问令牌、API 密钥或 Jupyter 凭据。
- 可直接用于访问生产环境的服务器地址或内部网络信息。
- 用户个人文件、私有日志或可识别个人身份的账户信息。
- 尚未公开的科研数据，或未经许可不得公开的材料。

所有截图与示例在发布前都会进行审查和脱敏处理。
